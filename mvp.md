Core MVP

1. **Target Role Selection** — choose Frontend, Backend, AI/ML, etc.
2. **Skill Input** — manually enter skills or upload resume.
3. **Skill Gap Analysis** — Strong / Partial / Missing skills.
4. **Readiness Score** — e.g. `72% match`.
5. **Skill Priority** — show which missing skills matter most.
6. **Personalized Roadmap** — what to learn and in what order.
7. **Skill Dependency Graph** — visualize how skills connect.

Best Features

8. **Job Description Analyzer** — paste a job posting → compare yourself.
9. **Resume → Automatic Skill Extraction**.
10. **GitHub Analysis** — infer skills from repositories.
11. **Skill Assessment** — quiz to verify claimed skill level.
12. **Multiple Job Comparison** — find skills common across jobs.
13. **Time-Based Roadmap** — “I have 30 days” → optimized plan.
14. **AI Career Chat** — ask why/what to learn next.
15. **Progress Tracking** — readiness increases as gaps are closed.

Best hackathon combo

**Resume → Skill Extraction → Target Role → Gap Analysis → Priority → Interactive Skill Graph → Personalized Roadmap → Job Description Match**
