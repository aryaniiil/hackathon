SKILL DATASET

Open dataset for
roles and skills.

100 roles, 200 mainstream skills, 1600 aliases. Stored in dataset/ as JSON and CSV with fuzzy matching.

Files

  • role_skills_dataset.json / .csv - 100 entries, each { role, skills[] } with 15-20 skills
  • skill_aliases.json - canonical to aliases list
  • skill_alias_map.json - flat alias to canonical for lookup
  • skill_normalizer.py - normalize_skill() and canonical_skill()

Example

{"role": "Frontend Developer", "skills": ["HTML","CSS","JavaScript","React","Artificial Intelligence",...]}

Mainstream focus

Top skills: Artificial Intelligence (100 roles), Data Analysis (100), Machine Learning (96), Python (84). No niche jargon.
