How to use the
analyzer.

Single HTML/CSS/JS frontend, 100-role dataset, alias-normalized matching.

Quick start

Open Website/index.html in a browser. No build step. Choose a role in get-started.html, enter skills comma-separated, and see gaps.

Dataset

Files live in dataset/ and Datasets/: role_skills_dataset.json (100 roles), skill_aliases.json (200 skills, 1600 aliases), skill_alias_map.json for fuzzy lookup, and skill_normalizer.py with normalize_skill().

Alias matching

Normalize by lowercasing and stripping spaces, underscores, hyphens and slashes. Example: machine_learning and ML both map to Machine Learning.

Styling

All pages share css/style.css with Helvetica, dark glass (#0A0A0A, #1A1C1E, #242629), mint accents used subtly, and sticky stacked cards.
