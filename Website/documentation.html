How to use
skilly.

Pick a role, show what you know, take a short test, and get your AI-powered current state - all in under 5 minutes.

1 - Create your account

Go to Get Started → enter Full name, Email, Password (6+ chars) → Create Account. Check your inbox for a 6-digit OTP via Supabase SMTP (also in spam, expires in 10 minutes). Enter it → you’re in. Already have an account? Use Sign In → email + password → OTP again. No demo - real verification only.

2 - Choose your target role

Dashboard → Start setup: Choose role & skills → search 160 roles (e.g., Frontend Developer, Data Engineer) in the 2×4 grid. Tap one → Continue.

3 - Tell us what you know

Search 216 skills (e.g., Python, React, SQL) - alias-aware: ml → machine_learning, py → python, reactjs → react. Tap to select (role skills show role badge) or type custom comma-separated at the bottom. The count shows X selected • 216 available.

4 - Take the test - 15 questions, 5 minutes

Click Take skill test (12 MCQ + 3 written) → Gemini generates 12 multiple-choice (4 easy, 4 medium, 4 hard, pick one) + 3 written reasoning (write 2-3 sentences, e.g., How would you debug a slow SQL query?). Timer is 5:00, progress shows 8/15 answered. Written is scored 0 (blank) / 1 (partial) / 2 (strong reasoning with trade-offs).

5 - See your result - human, not cryptic

After Submit, you see Test complete! → Beginner / Intermediate / Advanced / Expert + 11/18 • 61% → Multiple Choice 9/12 • Written 2/6 → mastery bars per skill (e.g., Python • Intermediate • 78% mastery) + Written feedback per question (1/2 Good start - add trade-offs) → Next focus.

Scoring is 18 points total: Beginner 0-40% • Intermediate 41-70% • Advanced 71-85% • Expert 86-100%. No -/12 - every point is explained.

6 - Your AI Current State - the main dashboard card

Click See my AI current state → Gemini is fed with all skills needed for your role (weighted 1-5) + what you claimed + test results + your written reasoning and returns:

  • Summary - 3 sentences on where you stand for that role
  • What you have (strong, mint) vs What you lack (priority, dashed)
  • Strengths / Gaps to close (test-validated)
  • Recommendation + Next steps 1-2-3 in priority order (highest weight first)

Readiness bar shows %. This is the only card on Dashboard - simple by design.

7 - History, Pricing, Account

Top nav: Dashboard (current state) | History (every attempt with role • level • 11/18 • MCQ/Written, click View → to reload) | Pricing (Free $0, Pro $9, Team $29) | Account (email, target role, tests taken, avg score, recent 5).

History is stored in Supabase Postgres via Python backend (test_history), not just browser. No local demo.

Tips

  • Answer written questions with steps + why + trade-off (e.g., “I’d add index because…, but trade-off is write slower”). That’s what AI scores 2/2.
  • Retake anytime: Dashboard → Retake test or Change role / skills.
  • On mobile, hamburger is on the left → tap to open nav.
  • Need help? See Our Team or How It Works.
